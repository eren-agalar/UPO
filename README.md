# UPO v1.5.0 · Ultimate Performance Optimizer

Game performance optimizer for Windows 10/11. Designer: **Eren Ağalar**

## 🆕 What's new
- **Automatic updates:** UPO finds, downloads and installs new versions by itself
- **Signed updates:** Every update is digitally signed; UPO never installs a file with an invalid signature
- **Settings → Update:** Turn automatic checks on/off, "Check now"
- Setup automatically reopens UPO after updating

## 📦 Which file should I download?
| File | Description |
|---|---|
| **UPO-Setup-1.5.0.exe** | ✅ Recommended. Setup wizard with automatic updates |
| **UPO-Portable-1.5.0.zip** | Single file, no installation (no automatic updates) |
| upo-update.json | Used by UPO itself, no need to download |

## ⚙️ Installation
1. Download and run **UPO-Setup-1.5.0.exe**
2. If Windows shows "Windows protected your PC", click **More info → Run anyway** (this appears because the file isn't signed with a code-signing certificate)
3. After setup, UPO opens with administrator rights

> If you're on v1.4 or older, install this version manually once; future updates will arrive automatically. Your settings and backups are kept.

## 🛡️ Safety
- No personal or hardware data is collected or sent
- Connects to the internet only to check for updates (can be turned off in Settings)
- Every settings change is backed up and can be undone with one click in **08 · Undo Everything**

# UPO v1.5.0 · Ultimate Performance Optimizer

Windows 10/11 için oyun performansı optimizasyon aracı. Tasarım: **Eren Ağalar**

## 🆕 Bu sürümde
- **Otomatik güncelleme:** UPO yeni sürümleri kendisi bulur, indirir ve kurar
- **İmzalı güncellemeler:** Her güncelleme dijital olarak imzalanır; UPO imzası tutmayan dosyayı asla kurmaz
- **Ayarlar → Güncelleme:** Otomatik kontrolü aç/kapa, "Şimdi kontrol et"
- Kurulum dosyası güncellemeden sonra UPO'yu otomatik yeniden açar

## 📦 Hangi dosyayı indirmeliyim?
| Dosya | Açıklama |
|---|---|
| **UPO-Setup-1.5.0.exe** | ✅ Önerilen. Kurulum sihirbazı, otomatik güncelleme destekli |
| **UPO-Portable-1.5.0.zip** | Kurulumsuz tek dosya (otomatik güncelleme yok) |
| upo-update.json | UPO'nun kendisi kullanır, indirmene gerek yok |

## ⚙️ Kurulum
1. **UPO-Setup-1.5.0.exe** dosyasını indirip çalıştır
2. Windows "Bilgisayarınız korundu" derse **Ek bilgi → Yine de çalıştır** (dosya dijital sertifikayla imzalı olmadığı için çıkar)
3. Kurulumdan sonra UPO yönetici yetkisiyle açılır

> v1.4 veya daha eski bir sürüm kullanıyorsan bu sürümü bir kez elle kur; sonraki güncellemeler otomatik gelir. Ayarların ve yedeklerin korunur.

## 🛡️ Güvenlik
- Hiçbir kişisel veya donanım verisi toplanmaz ya da gönderilmez
- İnternete yalnızca güncelleme kontrolü için bağlanır (Ayarlar'dan kapatılabilir)
- Her ayar değişikliği yedeklenir, **08 · Tümünü Geri Al** ile tek tuşla geri alınır
