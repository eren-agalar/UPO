# UPO v1.5.1 · Ultimate Performance Optimizer

Game performance optimizer for Windows 10/11. Designer: **Eren Ağalar**

## 🆕 What's new
- The top bar shows the full version number (e.g. **v1.5.1**)
- On the first launch after an update, the live log tells you UPO was updated
- Minor fixes

## 📦 Which file should I download?
| File | Description |
|---|---|
| **UPO-Setup-1.5.1.exe** | ✅ Recommended. Setup wizard with automatic updates |
| **UPO-Portable-1.5.1.zip** | Single file, no installation (no automatic updates) |
| upo-update.json | Used by UPO itself, no need to download |

> If you're on v1.5.0, UPO finds this update by itself: a "New version available" window appears on launch. Your settings and backups are kept.
